# TX16S Remote UI

Заміна розбитого екрана RadioMaster TX16S на смартфон або браузер.
Прошивка EdgeTX транслює справжній кадровий буфер назовні і приймає назад
емульований ввід, тому працює **все** — включно з меню Lua-скриптів.

## Швидкий старт

```bash
# 1. Розпакувати архів і зайти в каталог
cd tx16s-remote-ui
git init && git add -A && git commit -m "chore: початкова структура проєкту"

# 2. Підтягнути EdgeTX (в .gitignore, у репозиторій не потрапляє)
bash tools/setup-upstream.sh

# 3. Відкрити у VS Code і запустити Claude Code
code .
```

## Дві сесії

Проєкт ведеться у двох вікнах Claude Code в одному репозиторії.

| Сесія | Запуск | Для чого |
|---|---|---|
| **Асистент** | `/assistant` | розмова, рішення, задачі, рецензії. Коду не пише |
| **Команда** | `/catchup` | власне розробка |

Міст між ними — файли в `tasks/`, не копіпаст:

```
асистент ──► Мета / Критерії / Обмеження
команда  ──► Результат
асистент ──► Рецензія (перевіряє git diff сам, не вірить звіту)
```

## Агенти й моделі

Opus — там, де помилка дорога: архітектура, код у прошивці, залізо, рецензія.
Sonnet — робота з чіткими рамками. Haiku — механічні задачі.

| Агент | Модель | Роль |
|---|---|---|
| `protocol-architect` | opus | протокол, крос-компонентні рішення |
| `edgetx-firmware` | opus | C++ у EdgeTX |
| `hw-integration` | opus | електрика, розпіновка, RF |
| `code-reviewer` | opus | рецензія перед комітом |
| `esp32-firmware` | sonnet | прошивка моста |
| `webui-dev` | sonnet | клієнт у браузері |
| `upstream-watcher` | sonnet | rebase на нову версію EdgeTX |
| `build-runner` | haiku | збірка, вичавлювання помилок |
| `explorer` | haiku | пошук по кодовій базі EdgeTX |

Моделі задані псевдонімами (`opus`, `sonnet`, `haiku`) — це найстійкіший
варіант, бо не потребує правок при виході нових версій. Якщо треба
зафіксувати конкретну модель, у полі `model` можна вказати повний
ідентифікатор, наприклад `claude-opus-5`.

Чому `/handoff` і `/catchup` на Sonnet, а не на Opus: обидві команди жорстко
задані шаблоном, творчості там немає. Якщо якість передачі між сесіями почне
провисати — підніміть `model` у відповідному файлі.
