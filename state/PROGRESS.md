**Оновлено:** —

## Фокус зараз

Проєкт розгорнуто, усі стартові рішення прийняті, блокерів немає.

Перший крок: задача **0001** — зняти копію SD-картки, поставити правило
udev, переконатися, що `dfu-util -l` бачить пульт (вимкнений, по USB),
і пройти цикл «залити → перевірити → повернути» двічі.

Добра новина для цього етапу: DFU працює з вимкненим пультом, тобто
заливка прошивки екрана не потребує взагалі.

## Прогрес по етапах

- [ ] Етап 0 — прошивка наосліп і процедура відкату
- [ ] Етап 1 — розробка в симуляторі
- [ ] Етап 2 — перенесення на залізо (MVP 1 і 2)
- [ ] Етап 3 — бокові панелі керування (MVP 3)
- [ ] Етап 4 — стабілізація і безпека польотів
- [ ] Етап 5 — розширення

## Відкриті питання до людини

Немає. Усі стартові питання закрито 2026-07-25.

**Зафіксовано:**
- EdgeTX на пульті — 2.12.x → наша гілка базується на релізній гілці 2.12.
- Роз'єм AUX1 — крок 2.54 мм, підходять звичайні перемички Dupont.
- Середовище моста — чистий ESP-IDF (ADR-0004, замінює ADR-0001).
- Плати — DevKit v1 для розробки, C3 SuperMini кандидат у корпус (ADR-0003).
- Швидкість каналу — 921600 бод.
- Ризик завад знято: використовується зовнішній модуль через JR-відсік.
- ОС — Arch Linux, середовище описане в `docs/10-arch-linux.md`.
