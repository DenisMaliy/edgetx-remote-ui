# Журнал рішень

Короткі рядки. Великі рішення оформлюються як ADR у `docs/adr/` і додаються
сюди посиланням.

| Дата | Рішення | Причина | Де докладно |
|---|---|---|---|
| 2026-07-25 | Транспорт — AUX1, не USB CDC | у AUX1 є DMA на передачу; USB-C лишається вільним для накопичувача й VCP | `docs/06-hardware.md` |
| 2026-07-25 | Захоплення екрана — порівняння двох кадрових буферів | не залежить від LVGL API; переживе перехід LVGL 8 → 9 | `docs/02-architecture.md` |
| 2026-07-25 | Стиснення — RLE16, не LZ4 | інтерфейс однотонний, RLE дає 5–20× майже безкоштовно; LZ4-кодувальника в EdgeTX немає | `docs/02-architecture.md` |
| 2026-07-25 | Ввід — підмішування у драйвери, не в GUI | безкоштовно отримуємо довгі натискання, автоповтор, прискорення енкодера | `docs/05-hooks.md` |
| 2026-07-25 | Два коміти: нові файли / гачки | мінімізує конфлікти при rebase на нову версію EdgeTX | `CLAUDE.md` |
| 2026-07-25 | Міст ESP32 — PlatformIO, Arduino core 3.x + IDF для UART | швидкий старт без втрати контролю над гарячим шляхом; чистий IDF лишається запасним | [ADR-0001](../docs/adr/0001-esp32-framework.md) |
| 2026-07-25 | Дві сесії (асистент / команда), міст через `tasks/` | асистент отримує доступ до репозиторію і рецензує за доказами, а не за звітом; історія рішень лишається в git | [ADR-0002](../docs/adr/0002-assistant-team-bridge.md) |
| 2026-07-25 | Розробка на ESP32 DevKit v1, швидкість 921600 | два ядра знімають ризик таймінгів; 921600 вкладається у стелю наявного CP2102 і достатній за трафіком | [ADR-0003](../docs/adr/0003-bridge-board-and-baudrate.md) |
| 2026-07-25 | Ризик завад Wi-Fi ↔ RF-модуль знято | використовується зовнішній модуль через JR-відсік; зовнішня антена більше не обов'язкова | `docs/06-hardware.md` |
| 2026-07-25 | Міст обов'язково потоковий, без накопичення кадру | 255 КБ не влазять у пам'ять жодної з наявних плат | [ADR-0003](../docs/adr/0003-bridge-board-and-baudrate.md) |
| 2026-07-25 | Міст — чистий ESP-IDF, без Arduino | `esp_http_server` уміє WebSocket сам; ESPAsyncWebServer/AsyncTCP дають випадкові падіння; менше пам'яті для C3 | [ADR-0004](../docs/adr/0004-bridge-framework-espidf.md), замінює ADR-0001 |
| 2026-07-25 | Базова гілка EdgeTX — 2.12, не main | на пульті 2.12; вміст SD-картки прив'язаний до версії, збірка від main викличе попередження | `CLAUDE.md`, `tools/setup-upstream.sh` |
| 2026-07-25 | Крок роз'єму AUX1 — 2.54 мм | виміряно; підходять звичайні перемички Dupont | `docs/09-bom.md` |
