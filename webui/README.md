# Клієнт у браузері

Односторінковий застосунок без збірки, лежить у LittleFS на ESP32.

Головна вимога: **нуль жорстко зашитої специфіки пульта**. Роздільність,
перелік клавіш, наявність сенсора приходять у пакеті `HELLO`, панелі
керування будуються динамічно. Літерал `480` у коді = помилка.

Без зовнішніх залежностей і CDN: телефон підключений до точки доступу
пульта, інтернету там немає.

Каркас створюється на етапі 2.6, бокові панелі — етап 3.
