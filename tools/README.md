# Інструменти

| Файл | Що робить |
|---|---|
| `setup-upstream.sh` | клонує/оновлює EdgeTX у `upstream/edgetx` |
| `uart_loopback.py` | перевірка перетворювача USB-UART на 921600 (замкнути TX на RX) |
| `test_client.py` | (етап 1) тестовий клієнт: показує екран пульта у вікні |
| `proto_dump.py` | (етап 1) декодує потік протоколу для налагодження |

`test_client.py` і `proto_dump.py` пишуться на етапі 1 — вони потрібні, щоб
перевіряти прошивку без ESP32 і без браузера, підключившись перетворювачем
USB-UART напряму до AUX1.
