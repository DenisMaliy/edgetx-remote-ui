# Інструменти

⚠️ Ця таблиця — єдине місце, де інструмент можна знайти, не знаючи його назви.
Написав новий — додай рядок. Ненайдений інструмент дорівнює ненаписаному.

## Робота з пультом і мостом

| Файл | Що робить |
|---|---|
| `test_client.py` | тестовий клієнт: вікно з екраном пульта живцем і керування ним (TCP / послідовний порт / WebSocket) |
| `capture_check.py` | підключитись, зібрати цілий кадр, зберегти PNG. Доказом цілісності є **покриття пікселів**, а не число `FRAME_END` |
| `input_check.py` | керування за сценарієм: натиснути, дочекатись кадру, зняти PNG. Уміє й «загубити» пакет навмисно |
| `loss_watch.py` | **задача 0018:** гортає меню енкодером десять хвилин рівним темпом і розкладає втрати пачок за причинами (черга / відправлення / пам'ять) |
| `baud_probe.py` | **задача 0017:** перевірка запобіжника повернення швидкості — доказом є відмова, а не успіх |
| `release_watch.py` | замір відпускання вводу на живому пульті **незалежним каналом** (USB-джойстик), а не власними лічильниками |
| `uart_loopback.py` | перевірка перетворювача USB-UART на потрібній швидкості (замкнути TX на RX) |

⚠️ Заміри проти моста вимагають **рівно одного клієнта**: міст тримає один
сеанс, і другий витісняє перший. Телефон і інструмент з ПК одночасно
перетворюють замір на шум (задача 0012 — 53 витіснення за сеанс).

## Спільний код і тести

| Файл | Що робить |
|---|---|
| `remote_ui_proto.py` | протокол на боці ПК: кадрування, CRC, `HELLO`, RLE16, три транспорти. **Один примірник на всі інструменти** — два розійшлися б |
| `proto_test.py` | тести протоколу: еталонні вектори, кадрування, RLE16, сесія |
| `webui_serve.py` | програмний двійник моста ESP32: HTTP + WebSocket на ПК, щоб правити клієнт без заліза |
| `webui_probe.js` | проба браузерного клієнта без браузера |

## Пульт як джерело правди про самого себе

Три дрібні скрипти читають режим USB-джойстика — **незалежний канал**, яким
видно стан пульта без нашого протоколу. Саме тому вони й цінні: доказ, знятий
власним кодом, доводить лише те, що код узгоджений сам із собою.

| Файл | Що робить |
|---|---|
| `jsinfo.py` | скільки осей і кнопок віддає пульт, як він зветься |
| `jswatch.py` | 15 с показує події джойстика — чи ворушиться орган керування |
| `axprobe.py` | 22 с знімає осі через `evdev`, із діапазонами |

⚠️ Замір на 10 с бреше: рухаються лише стіки. На 30 с рухаються сім осей із
восьми (задача 0017).
