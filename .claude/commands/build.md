Зібрати ціль: $ARGUMENTS

Якщо ціль не вказана — збери симулятор X10 (`sim-x10`).

| Ціль | Що робити |
|---|---|
| `sim-x10` | симулятор EdgeTX під ПК, ціль X10 (SDL2) |
| `fw-tx16s` | прошивка пульта, `-DREMOTE_UI=YES` |
| `esp32` | `idf.py build` у `firmware/esp32/`, ціль `esp32` (DevKit v1) |
| `esp32-c3` | те саме під `esp32c3` (SuperMini) |
| `test` | юніт-тести протоколу |

Делегуй виконання агенту `build-runner`. Поверни тільки стислий результат:
успіх/помилка, розмір прошивки, вільне місце, або перші 3–5 справжніх
помилок компіляції.

Міст збирається **чистим ESP-IDF через `idf.py`**, без Arduino і без
PlatformIO (ADR-0004 + уточнення 2026-07-26). Середовище активується
`. ~/esp/esp-idf/export.sh`; версія, на якій міст збирався, — **v5.5.4**.

⚠️ Для `fw-tx16s`: docker у системі більше немає (перевстановлення
2026-08-01), але повний набір `arm-none-eabi-*` є. Збирай нативно і назви
версію компілятора — вона новіша за ту, під яку писався EdgeTX 2.12.

Довгі логи в основну розмову не тягни.
