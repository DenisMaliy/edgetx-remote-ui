Зібрати ціль: $ARGUMENTS

Якщо ціль не вказана — збери симулятор X10 (`sim-x10`).

| Ціль | Що робити |
|---|---|
| `sim-x10` | симулятор EdgeTX під ПК, ціль X10 (SDL2) |
| `fw-tx16s` | прошивка пульта, `-DREMOTE_UI=YES` |
| `esp32` | `pio run` у `firmware/esp32/` |
| `esp32-fs` | `pio run -t buildfs` — упакувати `webui/` у LittleFS |
| `test` | юніт-тести протоколу |

Делегуй виконання агенту `build-runner`. Поверни тільки стислий результат:
успіх/помилка, розмір прошивки, вільне місце, або перші 3–5 справжніх
помилок компіляції.

Для `esp32` окремо перевір і назви версію Arduino core / ESP-IDF, яку
підтягнула платформа — це важливо для ADR-0001.

Довгі логи в основну розмову не тягни.
